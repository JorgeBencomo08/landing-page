Informacion

CSS es el lenguaje de estilo que se utiliza para definir la presentación de una página web. Permite controlar el diseño, colores, fuentes, espaciado y otras características visuales.

HTML es el esqueleto de una página web. Define la estructura y el contenido: títulos, párrafos, imágenes, links, botones.

JavaScript es el lenguaje de programación que permite añadir interactividad a las páginas web. Se utiliza para manipular el DOM, manejar eventos, realizar peticiones HTTP, entre otros.

React es una biblioteca de JavaScript para construir interfaces de usuario. Permite crear componentes reutilizables y gestionar el estado de la aplicación de manera eficiente.
